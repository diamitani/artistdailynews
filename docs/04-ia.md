# 04. Information Architecture & Content Taxonomy — ArtistDailyNews.com

Artist Daily News (ADN) is engineered as an institutional-grade music industry intelligence hub, utility toolkit, and credentialing platform powered by the **Artispreneur** ecosystem.

---

## 1. Core Domain Object Model

```mermaid
classDiagram
    class Article {
        +String id
        +String title
        +String slug
        +String summary
        +List bullets
        +String takeaway
        +Pillar pillar [business | culture | ideas]
        +Category category [financial | streaming | tech-ai | legal-royalties | marketing | gear-production | a2im-indie | sync-licensing]
        +String sourceName
        +String sourceUrl
        +String originalUrl
        +DateTime publishedAt
        +Boolean isBreaking
        +Boolean isFeatured
        +Number readingTimeMinutes
    }

    class PillarHierarchy {
        +Pillar business [Economics, Catalogue M&A, PRO Splits, DSP Payouts]
        +Pillar culture [Festivals, Microgenres, Cultural Ruptures, Editorial]
        +Pillar ideas [Creative Strategy, Direct-to-Fan, AI Production]
    }

    class FeedSource {
        +String id
        +String name
        +String url
        +Category category
        +String tier
        +Boolean enabled
        +String status
        +DateTime lastSyncedAt
    }

    class Subscriber {
        +String id
        +String email
        +String role [Artist, Producer, Manager, Label, Attorney]
        +List topics
        +String tier [free, pro_insider, enterprise]
        +DateTime subscribedAt
    }

    class PressPassCredential {
        +String id
        +String applicantName
        +String email
        +String role
        +String targetEvent
        +String status [pending, approved, active, rejected]
        +String cryptographicBadgeId
        +DateTime issuedAt
    }

    class SponsorshipBooking {
        +String id
        +String packageId [masthead_hero, daily_dispatch, tool_sponsor, custom_takeover]
        +String sponsorName
        +String sponsorEmail
        +Number amountCents
        +String stripeCheckoutSessionId
        +String status
    }

    FeedSource --> Article : Ingestion & AI Synthesis
    Article --> PillarHierarchy : Categorization & Routing
    Article --> Subscriber : Syndication & Breaking Alerts
    Subscriber --> PressPassCredential : Role Verification & Pass Issuance
    Subscriber --> SponsorshipBooking : Audience Demographics & Rate Card
```
