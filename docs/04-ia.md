# 04. Information Architecture — ArtistDailyNews.com

## 1. Domain Object Model

```mermaid
classDiagram
    class Article {
        +String id
        +String title
        +String slug
        +String summary
        +List bullets
        +String takeaway
        +Category category
        +String sourceName
        +String sourceUrl
        +String originalUrl
        +DateTime publishedAt
        +Boolean isBreaking
        +Boolean isFeatured
    }

    class FeedSource {
        +String id
        +String name
        +String url
        +Category category
        +String tier
        +Boolean enabled
        +String status
    }

    class Subscriber {
        +String id
        +String email
        +String role
        +List topics
        +String tier
        +DateTime subscribedAt
    }

    class PressPassApplication {
        +String id
        +String applicantName
        +String email
        +String role
        +String targetEvent
        +String status
        +DateTime createdAt
    }

    class Sponsorship {
        +String id
        +String packageId
        +String sponsorName
        +String sponsorEmail
        +Number amountCents
        +String status
    }

    FeedSource --> Article : ingests & classifies
    Article --> Subscriber : syndicates via newsletter
    Subscriber --> Sponsorship : exposed to sponsor units
```

## 2. Navigation Taxonomy

- **Global Navigation (Header)**:
  - Today's Live Feed (`/`)
  - Royalties & Catalogues (`/topics/financial`)
  - Streaming & Playlists (`/topics/streaming`)
  - AI & Tech (`/topics/tech-ai`)
  - Podcasts & Interviews (`/podcasts`)
  - Royalty Calculators (`/tools`)
  - Apply for Press Pass (`/press-pass`)
  - Advertise / Media Kit (`/advertise`)
  - Newsroom Agent Studio (`/admin/newsdesk`)
- **Utility & Legal Navigation (Footer)**:
  - Google Ads.txt (`/ads.txt`)
  - Master RSS XML Feed (`/api/news/feed?format=rss`)
  - Newsletter Dispatch Archive (`/newsletters`)
